## 한 번 공부 (40분)
1. **10분 · 개념** — ① 정의 ② 왜 생겼나 ③ 공식
2. **15분 · 손으로** — ④ 손계산 ⑤ 파이썬 재현
3. **10분 · 프로젝트** — ⑥ 코드 읽기 ⑦ 예측 → 실험 (03 노트북에서 파라미터 하나 바꿔보기)
4. **5분 · 정리** — ⑧ 한계 ⑨ 면접 질문 → 커밋
